select(i, ...) directly as the final argument to FindFirstChild, which expanded
remaining path segments into optional parameters. A later string was therefore
received as FindFirstChild's recursive boolean argument, causing "Unable to cast
string to bool". The function now stores one segment before calling FindFirstChild.
